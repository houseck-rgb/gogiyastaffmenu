"7번 테이블" = chil-beon te-i-beul = Table 7. The grey number is the price — kitchen staff can ignore it.
3
Menu name + quantity
"x2" = make 2. For meat, x1 = one portion (200 g or 150 g, as printed on the ticket).

One line = one menu. Find the name in ② Menu names if you don't know it.
Same table, new bill = extra order
A second bill for the same table means they ordered more. Make only what is on the new bill.
Note: 추가 후식 된장찌개 is the stew's full name — do not prepare an additional item just because the menu name contains "추가".
Hall request bills (직원STAFF)
Hall staff send these when they need the kitchen to make or prepare something — rice, vegetables, sauces, or side dishes. For 김치, cut the kimchi into serving pieces (김치를 썰어 준비하기).
The bill shows 100,000원 — that is not a real price. Just make the item.

Key words — learn these first핵심 단어

Many menu names are made from these words. If you know them, you can read most of the bill.

Watch out — similar names
흑돼지 삼겹살 / 제육볶음 = pork · 소살치살 / 소불고기 = beef (소 = beef)
소살치살 = regular · 양념소살치살 = SEASONED — apply the designated seasoning!
양념소살치살은 양념·시즈닝 적용을 반드시 확인하세요.
Three cold noodles! 냉모밀 = buckwheat soba · 물냉면 = in broth · 비빔냉면 = spicy, no broth
Ignore "BBQ", "후식", "시원한", "♥소화짱♡" — find the main word.
